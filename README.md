# UI-киты — витрина стилей мобильного приложения

Один и тот же экран приложения (баланс + список операций + таббар) в пяти визуальных стилях.
Нужен, чтобы выбрать стиль до разработки.

1. **iOS / Cupertino** — Apple HIG, системный вид
2. **Material 3** — Google, фиолетовая палитра
3. **Dark / фиолетовый** — тёмная финтех-тема
4. **Neutral / shadcn** — белый, тонкие рамки
5. **Bold / цветные блоки** — крупная типографика, акцентный цвет

Открыть: https://abmarat11-art.github.io/ui-kits-preview/

Запуск локально: `python3 -m http.server 4477` и открыть `index.html`.
Скриншоты: `shots/`.
